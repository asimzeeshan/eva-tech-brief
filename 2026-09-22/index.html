Meta patches Muse macOS agent takeover flaw

Meta issued a patch for its Muse macOS app after researcher Patrick Wardle identified a vulnerability that could let an attacker take control of the AI agent. The reported attack requires local code execution and abuses an undocumented setting to redirect transcription processing away from Meta's servers, highlighting the importance of updating privileged desktop assistants.
