GhostLock Linux flaw enables root and container escape

Researchers disclosed GhostLock, a Linux kernel flaw described as present across mainstream distributions for years. The issue can allow local privilege escalation to root and container escape, so platform teams should track vendor patches and prioritize shared hosts and container infrastructure.
