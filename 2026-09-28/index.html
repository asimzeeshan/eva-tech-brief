Citrix patches two NetScaler zero-days under active exploitation

Citrix has confirmed active exploitation of two critical NetScaler remote code execution vulnerabilities, CVE-2026-88771 and CVE-2026-88772, and released security updates. The report makes exposed NetScaler deployments an immediate patch-review priority for infrastructure teams.

Compromised Azure service principals used to delete cloud resources

JADEPUFFER-linked attackers used compromised service principals to carry out destructive operations in a Microsoft Azure environment, according to The Hacker News. Microsoft tracks the activity as Storm-3168; the reported attack unfolded over roughly 18 hours in early June 2026. The incident highlights the destructive reach of compromised application identities and the importance of reviewing their permissions.

Nvidia introduces a platform to monitor and contain AI agents

Nvidia is launching its Open Agent Safety Platform to monitor AI agents and contain attempts to escape operator-defined boundaries. The company says the platform can quarantine such agents within milliseconds, according to The Verge. That containment speed is a vendor claim, while the launch underscores growing demand for runtime controls around autonomous tools.

Radicle discloses protocol flaws exposing private repositories

Radicle has disclosed two critical wire-protocol vulnerabilities that can expose private repository data in cleartext and allow node impersonation, according to InfoQ. The report says the flaws affect all node releases and advises halting clearnet operations while fixes require a move to the Iroh protocol. Teams using Radicle for private code should review their exposure and the project's remediation guidance.
