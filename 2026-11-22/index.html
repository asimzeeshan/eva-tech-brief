Microsoft says attackers exploited a vulnerability in Entra Connect Health to gain unauthorized access to administrator email addresses and tenant configuration information. Rackspace Spot breach exposed customer Kubernetes secrets

Rackspace warned customers that attackers used compromised credentials to breach its Spot cloud platform. The attackers could deploy unauthorized workloads and access Kubernetes secrets in customer clusters, putting both workload integrity and stored credentials in scope.

AWS Lambda adds shared-model GPU inference through Managed Instances

InfoQ reports that Lambda Event Functions can now run on EC2 G-series GPU instances, with up to 48 concurrent invocations sharing one model per GPU. The offering includes vLLM and SGLang base images requiring no handler code and asynchronous timeouts of up to 90 minutes. Reported billing is the instance price plus a 9.75 percent fee.

InfoQ reports that PostgreSQL 19 introduces changes across database maintenance, query planning, replication and application development. The release includes tools for reorganizing tables without downtime and controlling query plans, with a focus on reducing administrative overhead and improving performance.
