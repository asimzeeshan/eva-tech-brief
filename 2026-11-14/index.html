UnrealIRCd command-injection flaw faces active exploitation

The Hacker News reports that CISA added an UnrealIRCd vulnerability to its Known Exploited Vulnerabilities catalog following reports of active exploitation. The flaw affects the open-source IRC server and enables server-level command injection. Operators running UnrealIRCd should review the applicable advisory and remediation guidance.

PostgreSQL patches 52 flaws, including authenticated code execution

PostgreSQL updates address 52 security flaws, including a type-confusion issue that can let a database user with object-creation privileges execute code on the server. According to The Hacker News, full protection from that issue also requires rebuilding installed C-language extensions. Database teams should account for those extensions when planning the update.

Open-source DocumentDB 1.0 reaches general availability

DocumentDB 1.0 is the first generally available release of the MIT-licensed document database built on PostgreSQL. It supports the MongoDB wire protocol, with most MongoDB drivers, tools and queries working without changes, according to InfoQ. That compatibility makes it relevant to teams evaluating PostgreSQL-backed document storage.
