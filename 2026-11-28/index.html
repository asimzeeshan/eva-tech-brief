Public Cacti zero-day enables unauthenticated command execution

A publicly released exploit targets the Cacti network monitoring platform when its guest account is enabled; testing covered Cacti Core 1.2.31. The report advises disabling guest access and restricting the web interface to trusted networks while awaiting a patch. Compromise could expose monitoring credentials, although no attacks exploiting the flaw had been reported as of November 27.
