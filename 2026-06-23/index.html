Linux Foundation proposes Agent Name Service

The Linux Foundation plans to launch Agent Name Service, an open standard for giving AI agents trusted identities through DNS-like mechanisms. The goal is to let systems verify which organization an agent belongs to and what permissions it has before allowing it to act.

LastPass said attackers accessed customer data in its Salesforce environment after stealing OAuth tokens during the Klue supply-chain attack. The incident shows how third-party SaaS integrations can become the breach path even when the target's core infrastructure is not directly compromised.

GitHub updated actions/checkout to block common attack patterns involving pull_request_target workflows. The change is aimed at reducing software supply-chain risk where malicious pull requests can abuse elevated workflow permissions to run attacker-controlled code.

OpenAI launches open-source bug finding and patching push

OpenAI announced a new initiative focused on finding and patching vulnerabilities in open-source software. For developer teams, the important angle is not only AI-assisted discovery, but whether maintainers can absorb fixes quickly enough to shrink the window between disclosure and exploitation.

TechCrunch

AWS previews Blocks for AI-built backends

AWS released Blocks, an open-source TypeScript framework where each unit bundles application code, local mocks and deployable AWS infrastructure. It is designed so AI agents and developers can build locally without an AWS account, then deploy the same code to services such as Lambda, DynamoDB, Aurora and Bedrock.
