GitHub Breached: 3,800 Internal Repos Exfiltrated via Poisoned VSCode Extension

GitHub confirmed that TeamPCP (UNC6780) compromised an employee's device through a malicious VS Code extension, exfiltrating approximately 3,800 internal repositories. The group is seeking $50K+ on underground forums for the stolen source code. No customer data impacted so far. GitHub removed the extension, isolated the endpoint, and launched full incident response. TeamPCP has previously hit Aqua Trivy, CheckMarx KICS, LiteLLM, Telnyx SDK, TanStack, and MistralAI.

CISA Contractor Leaked AWS GovCloud Keys on GitHub for Six Months

A Nightwing contractor maintained a public repo called 'Private-CISA' containing 844MB of CISA internal data: AWS GovCloud admin keys, plaintext passwords, SAML signing certificates, and SSH keys. Exposed since November 2025, discovered May 14 by GitGuardian. The AWS keys remained valid for 48 hours after takedown - a credential revocation failure on top of the exposure. Called 'the worst government data leak' by researchers.
