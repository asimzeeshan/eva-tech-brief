Visa open-sources an autonomous security patching harness

Visa released an open-source agentic security harness that can find vulnerabilities, generate fixes, and subject its own patches to adversarial review before a human steps in. The default workflow spans 11 stages and can edit target source code, making careful operator controls essential.
